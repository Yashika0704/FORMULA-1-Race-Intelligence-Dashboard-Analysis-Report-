# 🏎️ Formula 1 Race Intelligence Dashboard

## 📌 About the Project
The Formula 1 Race Intelligence Dashboard is a data-driven project designed to analyze Formula 1 race performance, driver statistics, team standings, lap times, and race results.

It presents racing data in a simple and interactive way to help users understand race performance and compare drivers and teams.

## ✨ Features
- Driver performance analysis
- Team standings and comparison
- Lap time analysis
- Race results visualization
- Interactive data dashboard
- Easy-to-understand racing insights

## 🛠️ Technologies Used
- React
- TypeScript
- Vite
- Data Visualization

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/amiteshsathua07/Formula-1.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Formula-1
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🎯 Project Objective
The main objective of this project is to transform Formula 1 racing data into meaningful insights through data analysis and visualization.
