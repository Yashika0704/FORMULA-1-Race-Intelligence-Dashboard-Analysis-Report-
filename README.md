# 🏎️ Formula 1 Race Intelligence Dashboard

## 📌 About the Project
The Formula 1 Race Intelligence Dashboard is a data-driven project designed to analyze Formula 1 race performance, driver statistics, team standings, lap times, and race results.

It presents racing data in a simple and interactive way to help users understand race performance and compare drivers and teams.

## ✨ Features
- Driver performance analysis
- Team standings and comparison
- Lap time analysis
- Race results visualization
- Interactive data dashboard
- Easy-to-understand racing insights

## 🛠️ Technologies Used
- React
- TypeScript
- Vite
- Tailwind CSS
- Google Gemini AI (`@google/genai`)
- Data Visualization

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm
- A [Gemini API Key](https://aistudio.google.com/app/apikey)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Yashika0704/FORMULA-1-Race-Intelligence-Dashboard-Analysis-Report-.git
   ```

2. Navigate to the project folder:

   ```bash
   cd FORMULA-1-Race-Intelligence-Dashboard-Analysis-Report-
   ```

3. Install dependencies:

   ```bash
   npm install --legacy-peer-deps
   ```

4. Set up your environment variables:

   ```bash
   cp .env.example .env
   ```
   Then open `.env` and replace `MY_GEMINI_API_KEY` with your actual Gemini API key.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open **http://localhost:5173** in your browser.
